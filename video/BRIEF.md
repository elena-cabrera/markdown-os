# markdown-os marketing motion

Short kinetic promo aligned with the landing page (Inter, JetBrains Mono, neutral palette).

- **Duration:** 22s — intro, 3× ~3.6s feature+demo beats, “+ many more features”, CTA
- **Music:** `assets/music.mp3` (trimmed via `data-media-start`)
- **Workflow:** motion-graphics / kinetic-type + product highlights

## Commands

```bash
cd video
npm run dev      # preview
npm run check    # validate
npm run beats    # refresh beat grid from music
npm run render   # MP4 → renders/markdown-os-motion.mp4
```
